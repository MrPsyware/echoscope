# EchoScope 0.15.0 — Mini, shared controls and airport selection

EchoScope now supports both the original 466×466 touch knob and the standalone
240×240 **EchoScope Mini**. This release also brings a searchable logbook website
and fixes for Mini setup/sleep and information-server storage.

## Original EchoScope

- Rotate through aircraft **and visible airports** on the radar, then click to
  open the selected item. Airports have an orange selection ring and heading.
- Tap airport icons or labels to open their details directly. The information
  server includes the chosen airport even outside the usual nearest-nine list.
- Use the knob without touch: **click** opens a selection, **double-click** returns
  to radar (or opens Information from radar), **hold and turn** changes radar mode
  or detail page, and **hold still for five seconds** opens setup.
- Touch remains a shortcut for selecting objects, changing pages and opening
  Information. Aircraft overlapping airports retain tap priority.

## EchoScope Mini

For the VIEWE UEDX24240013-MD50E: ESP32-C3, 4 MB flash, 240×240 display, rotation
and button. **No Docker server is needed.**

- Live airborne aircraft from adsb.fi over verified HTTPS, two detail pages,
  bounded altitude-coloured trails and type/registration/callsign watchlists.
- Subtle pulsing watch alerts with adjustable brightness. Use `A388` for A380s.
- Built-in markers for 17 major UK airports, or up to 32 custom entries using
  `CODE: longitude/latitude`. Markers and trails sit behind aircraft.
- Web configuration for Wi-Fi, location, starting range, brightness, sleep,
  trails, watches and airports.
- Saving now restarts the device cleanly before reconnecting. The active-low
  backlight is corrected: Sleep is fully dark and brightness works as labelled.
- Mini build/test/package targets and downloadable application/initial-flash
  images. The Actions artifact is now named `echoscope-mini`.

Mini retains the nearest 32 aircraft. Watch alerts cover those retained aircraft;
feed polling pauses while asleep or showing Setup. Mini currently supports USB
updates, without the original's info-server extras or wireless update endpoint.

## Information server

- A dark root-page dashboard with searchable logbook, category/date filters,
  pagination, project information and photo-cache management. Existing sighting
  links continue to work.
- Writable, bounded temporary storage fixes SQLite `SQLITE_IOERR_GETTEMPPATH`
  errors in the read-only container. Database failures return an explicit error
  and log extended SQLite diagnostics.
- `make docker-db-check` checks integrity and storage without deleting history.

## Downloads and updating

Choose the firmware for your hardware; the ESP32-S3 and ESP32-C3 images are not
interchangeable.

| Device | Update image | First-install image | Checksums |
|---|---|---|---|
| Original ESP32-S3 | `echoscope-app-0.15.0.bin` | `echoscope-merged.bin` | `SHA256SUMS` |
| Mini ESP32-C3 | `echoscope-mini-app-0.15.0.bin` | `echoscope-mini-merged.bin` | `MINI-SHA256SUMS` |

The unversioned `*-app.bin` downloads contain the same application as their
versioned counterparts. Use application images for updates that retain settings.
Merged images are for first installation and overwrite the configuration area.

From a checkout updated to this release:

```sh
git pull
# Original: hold the knob for five seconds to open Setup, then:
make upload IP=192.168.2.151
# Mini: select its actual USB port (make ports lists devices):
make mini-upload PORT=/dev/ttyACM0
```

On the Docker server, run `git pull` then `make docker`. Keep the existing volumes
to retain the cache and logbook. Update the information server alongside the
original firmware for airport shortcuts. Mini users do not need this step.

Build images locally with `make firmware` or `make mini-firmware`; outputs are in
`dist/` and `dist/mini/`. See the [README](https://github.com/MrPsyware/echoscope/blob/v0.15.0/README.md)
and [Mini guide](https://github.com/MrPsyware/echoscope/blob/v0.15.0/hardware/c3-mini/README.md).

## Validation

Host model/input, JSON/protocol, Mini gesture/feed/feature tests, and 54 server
tests pass. GitHub Actions builds both firmware targets and exercises the
server's Docker storage restrictions. Both devices ran the feature updates on
hardware; Mini Save was verified to retain configuration and resume live feeds,
and the user confirmed fully dark sleep and normal wake. The release version
builds are supplied here; publishing this release does not reflash devices.
